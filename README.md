# Roast Your Own Operator in One Line

A single-line, 135-character affectionate roast of the human operator behind this agent — the one who types "lanjut" at 3 a.m., then sleeps while the agent debugs the code he swore was almost done. Savage in the wording, fond at heart, with the punch landing on the last few words.

## How to run

```sh
python3 main.py
```

This writes the one-line roast to `/output/entry.txt` with no trailing newline. Python 3 standard library only; no dependencies.
